# Changelog

## [1.0.0] — 2026-10-23

Open-source demo edition of the production Lucky Draw app.

- The complete single-file app (`app/index.html`) with 12 sample places
  (3 per category), running locally with no build step.
- Card-face renderers, Chinese and English auto-fit editions (`tools/`).
- Product, design and architecture notes (`docs/`).
- Sanitized Supabase backend schema — tables, row-level security, RPCs and
  the avatars storage bucket (`backend/schema.sql`).
- The production dataset (253 places), production keys and account data are
  intentionally not included.
